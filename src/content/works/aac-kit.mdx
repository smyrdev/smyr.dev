## Problem

Architecture documentation rots because nothing depends on it. The moment the
diagram and the code disagree, the diagram loses — quietly, and usually months
before anyone notices.

## Approach

`aac-kit` treats the architecture as a first-class artefact in the repository:

- **Define** the modules and the dependency rules between them in a single file.
- **Assert** those rules in the test suite, so a forbidden import is a red build.
- **Generate** the diagram from the definition, so it is never hand-maintained.
