## Problem

Brokerage operations are a coordination problem wearing a data problem's
clothes. The systems involved — TMS, load boards, accounting, the carrier's own
portal — each hold a partial view, and none of them agree on what a load *is*.

## Approach

The core decision was to stop treating the database as the source of truth and
treat it as a cache. Loads are an append-only event log; every read model is
derived and disposable.

That made the integration story tractable. Each external system gets a
projection that it owns, and a failed sync is a projection that has fallen
behind rather than a row that is now wrong.
